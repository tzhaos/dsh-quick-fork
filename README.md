# dsh-quick-fork

简体中文 | [English](README.en.md)

在对话中划选文字，选区上方浮出**一颗胶囊、两个按钮**：

- **添加到对话**：把选中内容作为一条带编号的**注释附件**放进当前输入框，鼠标悬停注释可以看到完整文字；发送时注释会作为上下文带入这一次提问
- **添加到临时对话**：在右侧栏打开一个**临时侧边对话**，选中内容作为引用带入第一次提问

> 版本 `0.6.0`。侧聊使用原生右栏 tab，但面板是新实现的精简侧聊；
> 不是主对话组件的直接复用。

## 为什么

读代码或评审方案时，经常想对某一句话追问，但不希望打断主线；也经常只想把一段内容作为注释带进输入框，继续补充问题。
`dsh-quick-fork` 把这两种动作放到选区上方：

1. 选中主对话里的一段文字
2. 浮出的胶囊提供两个动作：
   - **添加到对话**：输入框卡片内出现 `1. 注释 ×` 一类的注释 chip；悬停显示全文，× 可单独移除；可以连续添加多条
   - **添加到临时对话**：右侧栏出现临时对话，选中文本作为引用
3. 发送消息时，待发送的注释会作为 `Selected text N:` 上下文块插在这条消息最前面；发送成功后注释自动清空
4. 关掉标签或退出应用后，临时对话从视图中消失

## 当前实现

- `shell.overlay` 里监听选区，在选区上方显示两段式胶囊（两个按钮共用一颗胶囊，中间一条分隔线）
- 添加到对话把选中文字写进浏览器本地的**注释 store**（按 Session 分桶，持久化到 `localStorage`）
- 输入框卡片内通过 `conversation.input.overlay` slot 挂载注释层：在 `[data-composer-card]` 中、编辑器之前插入注释行；卡片重渲染或重新挂载时自动补回
- 注释 chip 显示序号与「注释」，鼠标悬停/键盘聚焦弹出浮层展示完整文字；`×` 移除后重新编号
- 发送时包装当前 Session 的 `prompt`：把注释拼成前置文本块，注释先乐观移出输入框；发送被拒绝时按原顺序恢复
- 添加到临时对话通过 `sessions.create({ cwd })` 创建空白子会话（不复制父会话历史）
- 注册原生右侧栏 tab 类型，打开一个 `quick-fork` tab
- tab 面板显示：选中引用、Markdown 消息列表、输入框、发送/停止
- 第一条消息自动把选中引用作为 Markdown 引用块带入
- 打开面板后自动聚焦输入框
- 子会话在 tab 打开期间保持活跃；`dsh-sidebar-sections` 会把它从侧边栏隐藏
- 关闭 tab 时 archive 并清理本地 meta
- 应用重启后，恢复的 tab 没有当前运行标记，会直接关闭，不会再次 fork
- 选区位于侧聊面板或任何可编辑输入框内时不显示胶囊，避免递归创建或无意义添加

## 数据与边界

- 注释只保存在浏览器 `localStorage`，不写入宿主草稿或会话数据；刷新页面后仍会恢复
- 注释上下文会作为用户消息开头的文本进入会话记录（DSH 目前没有原生的文本注释附件类型），因此发送后对用户和模型都可见
- 临时会话仍是真实 DSH Session，会写入宿主会话存储，但被侧边栏过滤隐藏
- 关闭临时对话时只 archive，不是物理删除；可在归档中恢复
- 选中文字只保存在 tab 的导航参数/本地 meta 与注释 store，不进入主会话草稿
- 面板不实现附件、审批、模型选择等完整主对话能力（后续迭代）

## 安装

```text
plugin_manager(action="install_bundle", target="<monorepo>/packages/dsh-quick-fork")
```

或使用主仓库安装脚本：

```powershell
node scripts/install-all.mjs
```

安装后完全退出 DSH 再启动。

## 已知限制

- 注释上下文以普通文本块进入用户消息，发送后在聊天记录里能看到这段上下文
- 每个会话最多 20 条注释，每条最多 20000 字符；侧聊引用仍只带前 2000 字符
- 发送采用乐观清理：消息被 Host 接受后注释即清空；如果随后在排队里撤回这条消息，注释不会自动恢复
- 注释行依赖输入框卡片 `[data-composer-card]` / `[data-input-scroll]` DOM 契约，DSH 大改布局时需要适配
- 依赖 DSH 右栏 tab 类型、Session create API 和 dsh-sidebar-sections 的临时会话过滤；DSH 升级后需要跟随适配
- 应用关闭时打开的临时 tab 会在下次启动时自动关闭；子会话保留为归档
- 不继承父会话历史；侧聊的上下文只有选中引用和后续追问
- 不递归：侧聊面板内不显示胶囊
