# dsh-quick-fork

简体中文 | [English](README.en.md)

在对话中划选文字，选区上方浮出**一颗胶囊、两个按钮**：

- **添加到对话**：把选中内容作为 Markdown 引用块插入当前会话的输入框，可以接着补充问题
- **添加到临时对话**：在右侧栏打开一个**临时侧边对话**，选中内容作为引用带入第一次提问

> 版本 `0.5.0`。侧聊使用原生右栏 tab，但面板是新实现的精简侧聊；
> 不是主对话组件的直接复用。

## 为什么

读代码或评审方案时，经常想对某一句话追问，但不希望打断主线；也经常只想把一段内容引用到输入框，继续补充问题。
`dsh-quick-fork` 把这两种动作放到选区上方：

1. 选中主对话里的一段文字
2. 浮出的胶囊提供两个动作：
   - **添加到对话**：引用块写入主输入框（一次可撤销编辑），焦点回到输入框
   - **添加到临时对话**：右侧栏出现临时对话，选中文本作为引用
3. 临时对话第一次发送时，引用会作为上下文自动带入；之后不会重复携带
4. 关掉标签或退出应用后，临时对话从视图中消失

## 当前实现

- `shell.overlay` 里监听选区，在选区上方显示两段式胶囊（两个按钮共用一颗胶囊，中间一条分隔线）
- 添加到对话通过会话输入的 `captureInsertion()` / `insertText()` 写入主输入框：一次可撤销的纯文本编辑；插入点失效时回退到 `setDraft`
- 选中文字按行格式化为 Markdown 引用块；输入框里已有草稿时用空行分隔
- 添加到临时对话通过 `sessions.create({ cwd })` 创建空白子会话（不复制父会话历史）
- 注册原生右侧栏 tab 类型，打开一个 `quick-fork` tab
- tab 面板显示：选中引用、Markdown 消息列表、输入框、发送/停止
- 第一条消息自动把选中引用作为 Markdown 引用块带入
- 打开面板后自动聚焦输入框
- 子会话在 tab 打开期间保持活跃；`dsh-sidebar-sections` 会把它从侧边栏隐藏
- 关闭 tab 时 archive 并清理本地 meta
- 应用重启后，恢复的 tab 没有当前运行标记，会直接关闭，不会再次 fork
- 选区位于侧聊面板或任何可编辑输入框内时不显示胶囊，避免递归创建或无意义插入

## 数据与边界

- 临时会话仍是真实 DSH Session，会写入宿主会话存储，但被侧边栏过滤隐藏
- 关闭时只 archive，不是物理删除；可在归档中恢复
- 选中文字只保存在 tab 的导航参数/本地 meta，不进入主会话
- 「添加到对话」只修改当前草稿，不发送消息；发送仍由宿主负责
- 面板不实现附件、审批、模型选择等完整主对话能力（后续迭代）

## 安装

```text
plugin_manager(action="install_bundle", target="<monorepo>/packages/dsh-quick-fork")
```

或使用主仓库安装脚本：

```powershell
node scripts/install-all.mjs
```

安装后完全退出 DSH 再启动。

## 已知限制

- 选中文本上限 2000 字符，超出部分不会被带入引用
- 「添加到对话」依赖宿主输入 shell；输入框暂时不可写时只显示提示，不改动草稿
- 依赖 DSH 右栏 tab 类型、Session create API 和 dsh-sidebar-sections 的临时会话过滤；DSH 升级后需要跟随适配
- 应用关闭时打开的临时 tab 会在下次启动时自动关闭；子会话保留为归档
- 不继承父会话历史；侧聊的上下文只有选中引用和后续追问
- 不递归：侧聊面板内不显示胶囊
